# Free Edit Form Presets (V1.0)

사용자가 빠르게 선택할 수 있도록 미리 정의된 편집 프리셋 세트입니다.

## 1. 프리셋 목록

### 1.1. 제품 리뷰 빠른 편집
- **목적**: 제품 리뷰
- **길이**: 3분 정도
- **스타일**: 빠르고 강하게
- **초반**: 실제 사용 장면 또는 결론 먼저
- **줄일 부분**: 긴 배경 설명, 반복 설명, 광고처럼 느껴지는 말
- **살릴 부분**: 실제 사용 장면, 솔직한 반응(리액션), 최종 후기
- **Matrix 모드**: `ccut_matrix_light` (2s, 8 slots)

### 1.2. 강의/설명 깔끔 편집
- **목적**: 강의/설명
- **길이**: CCUT 추천
- **스타일**: 설명을 잘 살리기
- **초반**: 자연스럽게 시작
- **줄일 부분**: 긴 침묵, 어색한 말, 준비 과정
- **살릴 부분**: 중요한 설명, 결론
- **Matrix 모드**: `ccut_matrix_light` (2s, 4 slots)

### 1.3. 인터뷰 핵심 요약
- **목적**: 인터뷰
- **길이**: 5분 정도
- **스타일**: 무난하고 깔끔하게
- **초반**: 결론 먼저
- **줄일 부분**: 어색한 말, 반복 설명, 긴 배경 설명
- **살릴 부분**: 감정 표현, 결론/후기, 중요한 설명
- **Matrix 모드**: `video_use_speech_only` (빠른 분석)

### 1.4. 브이로그 자연 편집
- **목적**: 브이로그
- **길이**: 원본의 절반 정도
- **스타일**: 감성 있게
- **초반**: 자연스럽게 시작
- **줄일 부분**: 준비 과정, 어색한 말
- **살릴 부분**: 웃음/리액션, 감정 표현, 실수/재미있는 장면
- **Matrix 모드**: `ccut_matrix_light` (5s, 4 slots)

### 1.5. 쇼츠 후킹 편집
- **목적**: 쇼츠/릴스
- **길이**: 1분 이내 (9:16 권장)
- **스타일**: 빠르고 강하게
- **초반**: 제일 강한 장면 먼저
- **줄일 부분**: 모든 긴 설명, 침묵
- **살릴 부분**: 웃음/리액션, 결론, 실수/재미있는 장면
- **Matrix 모드**: `ccut_matrix_light` (1s, 8 slots)

### 1.6. 그냥 보기 좋게 줄이기 (Auto-Trim)
- **목적**: 그냥 보기 좋게 줄이기
- **길이**: 원본의 절반 정도
- **스타일**: 무난하게
- **초반**: CCUT 추천
- **줄일 부분**: 긴 침묵, 중복 구간, NG 구간
- **살릴 부분**: 전체적인 흐름 유지
- **Matrix 모드**: `ccut_matrix_light` (5s, 4 slots)

## 2. 공통 적용 품질규칙
- 모든 프리셋은 `Word Boundary Snap`과 `Audio Pop Guard`를 기본 적용하여 컷 연결부의 물리적 품질을 보장합니다.
