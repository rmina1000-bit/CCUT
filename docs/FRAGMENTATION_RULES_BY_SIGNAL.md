# Fragmentation Rules by Signal (V1.0)

인지 신호 매트릭스(CSM) 데이터를 기반으로 의미 조각(Semantic Fragment)의 경계를 결정하는 세부 규칙입니다.

## 1. 신호별 조각화 기준

### 1.1. speech_signal (언어적 경계)
- **문장 끝**: 마침표(.) 또는 긴 호흡(0.5s 이상)이 발생하는 지점.
- **침묵(Silence)**: 유효 음성 데이터가 없는 구간이 1s 이상 지속될 때.
- **화자 변화**: 대화 주체가 변경되는 시점.
- **반복/실수**: 동일 키워드가 짧은 간격으로 반복되거나 분석 결과 "실수" 패턴이 감지될 때.

### 1.2. scene_signal (시각적 경계)
- **Hard Cut**: 화면 데이터가 급격히 변하여 장면 전환 점수가 0.9 이상인 지점.
- **Fade In/Out**: 점진적 변화가 시작되거나 끝나는 지점.
- **장소 변화**: 시각적 배경 데이터의 통계적 유의미한 차이가 발생할 때.

### 1.3. person_signal (인물 경계)
- **인물 등장/퇴장**: 화면 내 새로운 인물이 감지되거나 기존 인물이 사라질 때.
- **표정 변화**: 중립 상태에서 특정 감정(웃음, 놀람)으로 급격히 전환될 때.
- **화자 변경**: 입 모양 분석과 오디오 신호가 결합되어 주 화자가 바뀌는 시점.

### 1.4. motion_signal (역동적 경계)
- **모션 시작**: 정지 상태에서 유의미한 움직임(피사체 또는 카메라)이 시작되는 시점.
- **정점(Peak)**: 움직임의 속도가 최고조에 달했다가 감소하기 시작하는 지점.
- **종료**: 움직임이 잦아들고 화면이 다시 안정되는 지점.

### 1.5. audio_signal (청각적 경계)
- **음량 변화**: 배경음악이 커지거나 갑자기 작아지는 지점(Ducking/Bridge).
- **특이음 감지**: 박수, 웃음소리, 물건 떨어지는 소리 등 특정 오디오 이벤트 발생 지점.
- **잡음 구간**: 엔진 소리, 바람 소리 등 환경 잡음이 음성을 덮는 구간의 시작과 끝.

### 1.6. event_signal (행위 경계)
- **리액션**: 특정 사건에 대한 인물의 반응이 나타나는 구간.
- **실수/NG**: 작업 수행 중 오류가 발생하여 재시도가 일어나는 구간.
- **성공/환호**: 특정 미션이 완료되어 긍정적인 신호가 집중되는 구간.

### 1.7. focus_object_signal (객체 경계)
- **제품 등장**: 리뷰 대상 제품이 화면 중앙에 배치되거나 포커스가 잡히는 시점.
- **로고 노출**: 브랜드 로고가 명확하게 인식되는 구간.

## 2. 복합 신호 통합 규칙 (의미 조각 생성 예시)

의미 조각은 단일 신호가 아닌 여러 신호의 조합으로 완성됩니다.

**예시: "제품 실사용 긍정 리액션 조각"**
1. `speech`: "와, 이거 진짜 괜찮은데요?" (긍정 텍스트)
2. `motion`: 손동작이 제품 쪽으로 빠르게 이동 (관심 표현)
3. `focus_object`: 제품이 선명하게 중심부에 위치 (리뷰 대상)
4. `event`: 웃음/놀람 신호 감지 (감정 반응)
5. `entropy`: 화면의 색상 대비 및 정보량 증가 (집중 구간)
→ 위 5가지 신호가 특정 시간 구간(Row들)에 중첩될 때 하나의 의미 조각으로 확정합니다.
