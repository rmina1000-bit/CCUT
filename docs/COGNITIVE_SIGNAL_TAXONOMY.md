# Cognitive Signal Taxonomy (V1.0)

Cognitive Signal Matrix의 각 열(Column)을 구성하는 인지 신호의 분류 체계입니다.

## 1. 신호 목록 및 정의

### 1.1. speech_signal
- **측정**: 음성 텍스트화(ASR), 화자 식별, 핵심 키워드 추출.
- **출력**: 텍스트, 화자 ID, 키워드 리스트.
- **중요성**: 대화 중심 영상에서 편집 경계를 결정하는 가장 핵심적인 신호.
- **정책**: **무료 포함**

### 1.2. scene_signal
- **측정**: 샷 경계 검출(Shot Boundary Detection), 시각적 유사도 변화.
- **출력**: 장면 전환 점수(0.0 ~ 1.0), 키프레임.
- **중요성**: 영상의 시각적 호흡과 장소 이동을 파악하는 기준.
- **정책**: **무료 포함**

### 1.3. person_signal
- **측정**: 얼굴 인식, 인물 등장/퇴장, 표정 분석.
- **출력**: 인물 ID, 감정 상태, 화면 점유율.
- **중요성**: 특정 인물 중심 편집(예: 리액션 모음) 시 필수적.
- **정책**: **유료(Full)**

### 1.4. motion_signal
- **측정**: 옵티컬 플로우, 카메라 움직임(Zoom, Pan), 피사체 이동량.
- **출력**: 모션 벡터 크기, 움직임 유형.
- **중요성**: 하이라이트 구간(역동적 구간) 추출에 사용.
- **정책**: **무료(Light)**

### 1.5. audio_signal
- **측정**: RMS 에너지, 스펙트럼 변화, 배경음/효과음 분리.
- **출력**: 음량 레벨, 오디오 유형(음성/음악/잡음).
- **중요성**: 배경음악 비트에 맞춘 편집이나 오디오 사고 구간 제외에 필요.
- **정책**: **무료 포함**

### 1.6. event_signal
- **측정**: 특정 행위(박수, 웃음, 낙하 등)의 고수준 이벤트 인식.
- **출력**: 이벤트 태그, 확률 점수.
- **중요성**: 재미있는 포인트나 핵심 액션 구간을 자동 포착.
- **정책**: **유료(Full)**

### 1.7. rhythm_signal
- **측정**: 시각적/청각적 정보의 밀도 변화율.
- **출력**: 템포(Fast/Slow/Static).
- **중요성**: 영상의 전체적인 편집 템포(Pacing) 조절에 기여.
- **정책**: **무료(Light)**

### 1.8. visual_entropy_signal
- **측정**: 화면 내 정보량(Complexity), 색상 분포 변화.
- **출력**: 엔트로피 점수.
- **중요성**: 화면 전환이 없더라도 내부 요소가 복잡해지는 구간 감지.
- **정책**: **유료(Full)**

### 1.9. focus_object_signal
- **측정**: 제품, 중요 사물, 텍스트 자막(OCR) 검출 및 추적.
- **출력**: 객체 클래스, 위치 좌표, 브랜드 로고 여부.
- **중요성**: 리뷰 영상에서 제품이 강조되는 시점 포착.
- **정책**: **유료(Full)**

## 2. 분석 모드별 신호 구성
- **Speech-Only**: `speech_signal`, `audio_signal`
- **Matrix Light**: `speech`, `scene`, `motion`, `audio`, `rhythm`
- **Matrix Full**: 모든 신호 포함
