# External API Cost Governance Policy (V1.0)

CCUT이 제공하는 유료 외부 AI 연동 서비스의 비용 관리 및 투명성 정책입니다.

## 1. 핵심 정책
- **사용자 별도 부담**: 외부 API(OpenAI, Anthropic 등) 비용은 사용자가 사용한 만큼 해당 업체에 직접 지불합니다.
- **CCUT의 역할**: CCUT 요금(9,900원)은 외부 AI 비용을 포함하지 않으며, 대신 이를 효율적으로 관리, 추정, 통제하는 **'거버너(Governor)'** 역할을 수행합니다.

## 2. CCUT의 책임 및 기능
1. **예상 비용 표시**: 분석/제안 시작 전, 데이터 크기를 기반으로 한 예상 API 비용을 사용자에게 미리 표시합니다.
2. **사용량 추적**: 실시간으로 호출된 토큰 수와 비용을 기록합니다.
3. **사용 한도 설정**: 사용자가 설정한 작업당/일별/월별 한도에 도달하면 호출을 즉시 중단합니다.
4. **고비용 호출 승인**: 특정 금액(예: 1,000원) 이상의 대규모 분석 시 사용자에게 재승인을 요청합니다.
5. **오류 및 상태 알림**: API Key 오류, 잔액 부족, 한도 초과 등의 상태를 즉시 알립니다.
6. **데이터 투명성**: 외부로 전송되는 데이터의 종류와 양을 사용자가 확인할 수 있도록 기록합니다.

## 3. 사용자 안내 예시 (UI Concept)
- "이번 작업 예상 외부 AI 비용: **약 320원** (GPT-4o mini 기준)"
- "현재 월 누적 사용량: **4,120원** / 한도: **10,000원**"
- "안내: 원본 영상 파일은 외부 AI로 전송되지 않으며, 텍스트 전사와 분석 메타데이터만 활용됩니다."

## 4. 정책의 의의
- CCUT은 외부 AI 업체와의 정산 리스크를 부담하지 않음으로써 서비스를 안정적으로 유지합니다.
- 사용자는 자신이 원하는 수준의 AI를 직접 선택하고 비용을 투명하게 관리할 수 있습니다.
