# Free Edit User Flow (V1.0)

CCUT 무료 사용자의 서비스 이용 경험 흐름과 시스템의 데이터 처리 단계를 정의합니다.

## 1. End-to-End Flow

1. **영상 업로드**: 로컬 파일을 CCUT으로 드래그 앤 드롭.
2. **기본 분석 (Matrix Scan)**:
   - CCUT이 기기 사양을 감지하여 최적의 `ccut_matrix_light` 또는 `speech_only` 모드로 배경 분석 시작.
   - Quick Scan 결과를 10초 내에 표시.
3. **폼 자동 제안 및 선택**:
   - 영상 내용을 분석하여 최적의 **프리셋** 하나를 자동 추천.
   - 사용자는 추천된 프리셋을 그대로 사용하거나, 8가지 항목의 **쉬운 편집 폼**을 수정.
4. **Edit Instruction 생성**:
   - 폼 선택값이 내부 JSON 지시서로 변환됨.
5. **의미 조각(Fragment) 제안 및 개입**:
   - 시스템이 조각 리스트를 A/B 안으로 제안.
   - 사용자는 타임라인 막대가 아닌 **조각 단위**로 아래와 같이 개입:
     - **살리기/빼기**: 특정 구간 포함 여부 결정.
     - **앞으로 보내기**: 순서(Order) 조정.
     - **짧게 줄이기**: 조각 내부의 Trim 힌트 제공.
     - **이 조각으로 시작하기**: Hook 지정.
6. **로컬 편집 및 검수**:
   - 사용자 개입이 반영된 최종 `ExportInput` 생성.
   - `Render QA` 규칙에 따라 물리적 오류(말 잘림 등) 자동 검사.
7. **최종 출력**: 원본 기반의 mp4 파일 생성 및 로컬 저장.

## 2. 무료/유료 서비스 차별화 (Checklist)

| 기능 | 무료 (Free) | 유료 (Standard) |
|------|-------------|-----------------|
| **분석** | 로컬 Cognitive Matrix | 클라우드 + 외부 AI 보강 |
| **편집 지시** | 규칙 기반 폼 (Static Form) | 외부 AI 기획자 (Chat/Direct) |
| **제안** | 기본 A/B 추천 | 무제한 AI 재제안 |
| **품질** | 필수 품질 규칙 (Word Snap 등) | 딥러닝 기반 정밀 검수 |
| **저장** | 로컬 프로젝트 | 서버 아카이브 저장 |
| **데이터 연동** | 단일 기기 | 기기 간 프로젝트 공유 |

## 3. 조각 기반 개입 원리
- 사용자의 조작(살리기, 빼기 등)은 즉시 `preserve_rules`, `avoid_rules`, `order_hint` 등의 필드로 변환되어 `Edit Instruction`을 실시간 업데이트합니다.
- 타임라인을 직접 자르고 붙이는 노동 없이, 데이터의 "상태"를 바꾸는 것만으로 편집을 완성합니다.
