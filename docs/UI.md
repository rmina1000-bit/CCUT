# UI Design Principles — Narrative Consultation

## Center Panel — Narrative Chat Area

The center panel is not a form panel and not a report panel.  
It is a conversation space.

During Narrative Consultation:
- A/B proposals are hidden
- no edit preview video is shown
- the assistant writes a narrative draft
- the user responds through the same chat input
- messages accumulate vertically
- quick reply chips are secondary
- the input box is the primary interaction method

## Chat Form Rule

CCUT must not invent a new chat grammar.  
The chat should feel familiar to users already accustomed to ChatGPT-style conversation.

UX requirements:
- natural line wrapping
- accumulated message history
- calm assistant messages
- user messages should not use strong or distracting colors
- white/gray-centered contrast
- suggestion chips should be subtle
- no PPT/report card feeling

## Prohibited UI

- Large report cards for conversation
- PPT-like narrative boxes
- Strongly colored user bubbles
- Replacing previous messages instead of accumulating them
- Button-first workflow
- Making quick replies feel like mandatory form choices
