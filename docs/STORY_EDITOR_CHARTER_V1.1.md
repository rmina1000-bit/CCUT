# Story Editor 헌장 v1.1 증보 — 대본(시나리오) 편집실

> 국장 확정 (2026-07-13). MASTER CONCEPT 1.0 + 이 증보 = v1.1. 충돌 시 증보가 이긴다.
> 전제 문서: [CCUT_MASTER_CONCEPT_1.0.md](CCUT_MASTER_CONCEPT_1.0.md)

## 1. 재정의 — CCUT의 첫 화면은 편집기가 아니라 "대본"이다

- 명칭: Story Document → **대본 (Scenario / Story Script)**.
- 사용자는 문서를 편집하는 게 아니라 **방송 대본을 다듬는 작가**다. 그 뒤에서 CCUT이 감독·편집기사·자막·음향처럼 움직인다.
- 대본은 정보를 읽는 문서가 아니라 **감정을 읽는 문서**다. 파일명·시간·ID·confidence는 대본 본문에 들어오지 못한다. 필요하면 "이 장면이 왜 여기 있어?"라고 물었을 때만 AI가 설명한다.

## 2. 지문 도입 — 대본 = 대사 + 지문

```
(새벽. 바닷가. 파도가 잔잔하다.)      ← 지문 (이탤릭)
오늘은 여기서 시작해보겠습니다.        ← 대사 (정체)
(아이가 모래를 만진다.)
괜찮아. 아빠 좀 봐.
```

- 지문 = 장면 태그의 노출이 아니라, AI가 태그를 **사람의 문장으로 번역**해 쓴 원고 본문. `subway car, child (장소:지하철)` → `(지하철 안. 아이가 보인다.)`
- 지문도 **Story Item** — 대사와 동등하게 hover·클릭·삭제·이동. 지문을 지우면 그 영상 구간이 사라진다.
- 말 없는 구간(바람·꽃·풍경)은 지문만으로 대본에 존재 → 무발화 영상 문제의 구조적 해소.
- 환각 자막 구간은 대사 대신 지문으로 대체 표기(원문은 상세 보기에 보존 — 정직 원칙).

## 3. 검증보고서 반영 확정 5건 (SCRIPT-2~5 로드맵)

1. **문장 내부 편집** ("'정말'만 빼"): 문단을 그 순간만 세분화 → word 타임스탬프 → EXCLUDE_RANGE (B0 계약 그대로).
2. **전사 교정 레이어**: Evidence 불변 + 사용자 교정본은 표시 레이어 + Receipt. 교정 = 그 가족 고유명사 사전(학습 재료).
3. **Undo·버전**: Ctrl+Z 스택 + 버전 스냅샷("오늘 아침의 대본으로"). Edit State revision 기반.
4. **리듬 분업 명문화**: "대본은 무엇을 남길지의 문서다. 어떻게 이을지(호흡·전환·박자)는 CCUT의 일이다."
5. **러닝타임 1줄 + 실행 후 확인**: 상단 "현재 12:40 → 목표 8:00"만(문단별 시간 숨김). 수정 직후 "3개 문단 제외, 42초 짧아짐."

## 4. 구현 현실 부기 (실측 기반)

- 무자막 11개 소스는 조각 자체가 없다(PHASE A: 무자막 = 미조각화). 지문이 서려면 이들의 장면 변화 기반 조각화가 선행 — **별도 마일스톤**(지문 렌더 1차와 분리).
- 지문 생성은 결정론 템플릿(태그·장소 → 한국어 서술문)으로 시작, 로컬 LLM 다듬기는 후속 (개념서 §12 분업).
- R2 백로그(사용성): 목차·검색·접기·즐겨찾기·AI 추천 버튼·동일 시간대 중복 처리.

## 5. 구현 현황 (SCRIPT-1 완료)

- 지문 결정론 템플릿: `ccut_backend/scenario_text.py` (실측 어휘 307조각 기반, 전수 94% 지문 생성).
- 대본 read API: `ccut_backend/ledger_r0.py` — 대사(dialogue)/지문(stage_direction)/환각원문(original_text) 분리, 좌표 기반 visual_desc 복원(D8 대응), 러닝타임.
- 대본 화면: `ccut_frontend/src/pages/LedgerPage.tsx` — 지문 이탤릭 + 대사 정체, 어느 줄이든 클릭 재생, 환각 '원문 보기', 상단 러닝타임. 명칭 '대본'.
- 마일스톤 순서: SCRIPT-1(지문 렌더) ✅ → SCRIPT-2(문장 내부 편집) → 3(전사 교정) → 4(Undo/버전) → 5(소품) / [별도] 무발화 소스 조각화.
