# Free Form UI Layout Guide (V1.0)

CCUT 무료 폼 UI의 공간 구성 및 배치 가이드라인입니다.

## 1. 좌측 패널 (Sidebar)
- **위치**: 화면 왼쪽 250px ~ 300px 고정 너비.
- **구성**:
  - **CCUT 로고**: 상단 좌측.
  - **새 프로젝트 버튼**: 로고 바로 아래, 가로 전체를 채우는 형태. (흑백 강조 스타일)
  - **메뉴 리스트**: 프로젝트, 아카이브, 보고서, 설정 순.
  - **상태 표시**: 하단에 현재 모델 로드 상태 및 무료 버전 배지 표시.

## 2. 중앙 패널 (Edit Form)
- **위치**: 화면 중앙, 가변 너비 (가장 넓은 영역).
- **구성**:
  - **섹션화**: 8개 폼 항목을 논리적 그룹으로 묶어 배치.
  - **컨트롤**: Pill Button(타원형) 또는 Segmented Button 사용.
  - **CTA**: 하단 중앙에 "편집안 생성" 버튼을 가장 크고 명확하게 배치.

## 3. 우측 패널 (Fragment & Preview)
- **위치**: 화면 오른쪽 350px ~ 400px 고정 너비.
- **구성 (상하 배치)**:
  - **상단**: 원본 파노라마 (전체 흐름 파악용).
  - **중간**: 조각 보드 (Fragment Board) - 수직 스크롤 형태의 조각 리스트/카드.
  - **하단**: 미리보기 플레이어 및 출력 제어부 (로컬 렌더, mp4 출력).

## 4. 하단 상태줄 (Footer)
- **위치**: 화면 최하단 30px ~ 40px.
- **구성**: 분석 진행률, 저장 위치 정보, 하드웨어 리소스 사용량(Governor 로그).

## 5. 화면 우선순위 (Hierarchy)
1. **무료 편집 폼**: 사용자가 가장 먼저 마주하고 정보를 입력해야 할 주인공.
2. **조각 보드**: 입력 결과가 나타나는 실질적인 작업대.
3. **새 프로젝트 버튼**: 서비스 시작의 핵심 트리거.
