## 1. 배경 및 핵심 아이디어

### 문제 인식
사용자 소스 영상이 부족하거나, 특정 장면(브릿지 컷, B-roll)이 없을 때
CCUT 단독으로는 해당 구간을 채울 수 없다.

### 해결 방향: CCUT × 외부 영상 생성 AI
```
CCUT 분석 결과(메타데이터만) → 외부 AI API → 생성 클립 반환
생성된 클립 → CCUT 로컬 렌더링 파이프라인으로 처리
```

### 핵심 원칙 (불변)
1. **원본 영상은 절대 외부로 전송하지 않는다.**
2. 외부 AI에 보내는 것: 텍스트 프롬프트 + 참조 스틸 프레임(jpg) 최소 1~3장
3. 렌더링은 항상 CCUT 로컬에서 FFmpeg으로 처리한다.
4. 외부 AI 생성 클립은 일반 소스 클립과 동일하게 취급한다.
5. 외부 API 사용은 **사용자 명시적 동의 후에만** 실행한다.

## 2. 적용 시나리오

### 시나리오 A — 부족한 B-roll 자동 채우기
```
[CCUT 분석] "이 구간에 닭이 뛰는 장면이 필요한데 소스에 없음"
    ↓
[API 호출] "닭이 풀밭을 뛰어다니는 장면, 4초, 낮 조명, 핸드헬드"
    ↓
[클립 반환] Runway / Kling → 4초 mp4 클립
    ↓
[CCUT 편집] 해당 클립을 일반 소스처럼 타임라인에 삽입 → 렌더링
```

### 시나리오 B — 스타일/분위기 변환 (Video-to-Video)
```
[사용자] "이 클립 분위기를 영화 같은 느낌으로 바꿔줘"
    ↓
[CCUT] 해당 클립의 스틸 프레임 3장 추출 + 스타일 프롬프트 생성
    ↓
[Runway Gen-4.5 Aleph] 스타일 변환 클립 생성
    ↓
[CCUT] 변환 클립으로 대체 후 렌더링
```

### 시나리오 C — 전환 연결 클립 생성
```
[CCUT 분석] A 장면(낮) → B 장면(저녁) 사이 전환이 부자연스러움
    ↓
[API 호출] A 마지막 프레임 + B 첫 프레임 참조 → "자연스러운 전환 3초 클립"
    ↓
[CCUT] 전환 클립 삽입 → 렌더링
```

## 3. 외부 API 후보 비교

| 서비스 | 초당 비용 | 내 소스 영상 참조 | JSON 명령 방식 | CCUT 우선순위 |
|--------|-----------|-------------------|----------------|---------------|
| **Runway Gen-4.5** | ~$0.10/초 | ✅ Video-to-Video | ✅ Scene Script JSON | 1순위 |
| **Kling 3.0** | $0.03~0.10/초 | ✅ 참조이미지+영상 | ✅ REST API | 2순위 |
| **Hailuo MiniMax** | $0.01~0.03/초 | 제한적 | ✅ API | 저비용 대안 |
| **Google Veo 3.1** | $0.08~0.15/초 | 스틸 이미지만 | ✅ Gemini API | 참고용 |
| **fal.ai** | 모델별 상이 | ✅ 통합 접근 | ✅ 단일 API 키 | 멀티모델 게이트웨이 |

### 1순위: Runway Gen-4.5 선정 이유
- `gen4_aleph`: 기존 영상 클립을 직접 참조해서 스타일 변환 가능
- JSON Scene Script: `{"shots": [{"prompt": "...", "duration": 4}]}` 방식
  → Video-Use 철학과 동일한 "명령어만 보내기"
- Director Mode: 카메라 동작(pan/tilt/zoom/dolly)을 API로 지정 가능

## 4. CCUT 통합 아키텍처

```
┌─────────────────────────────────────────────────────────┐
│  CCUT 분석 레이어 (기존 파이프라인)                       │
│  Semantic Fragment → Proposal Engine                     │
└─────────────────────┬───────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────┐
│  Gap Detector (신규)                                     │
│  - 타임라인에서 "빈 구간" 또는 "보완 필요 구간" 탐지      │
│  - AI 생성 클립이 필요한지 판단                           │
│  - 사용자에게 사용 여부 동의 요청                         │
└─────────────────────┬───────────────────────────────────┘
                      ▼ (사용자 동의 시)
┌─────────────────────────────────────────────────────────┐
│  External AI Adapter (신규)                              │
│  - 스틸 프레임 추출 (FFmpeg)                              │
│  - 프롬프트 자동 생성 (Semantic Fragment 기반)            │
│  - Runway / Kling / Hailuo API 호출                      │
│  - 생성 클립 다운로드 → storage/ai_generated/ 저장       │
└─────────────────────┬───────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────┐
│  CCUT 로컬 렌더링 (기존 FFmpeg 파이프라인)                │
│  - AI 생성 클립을 일반 소스처럼 취급                      │
│  - 타임라인 삽입 → 최종 렌더                              │
└─────────────────────────────────────────────────────────┘
```

## 6. 비용 통제 정책

### 자동 차단 규칙
- 1회 API 호출 최대 생성 길이: **8초**
- 1개 프로젝트 당 AI 생성 클립 최대: **60초**
- 초과 시 사용자에게 경고 후 중단

### 비용 예측 표시
사용자가 "AI 생성" 버튼 클릭 전에 반드시 예상 비용 표시:
```
예상 비용: $0.80 (Runway, 8초)
또는
예상 비용: $0.24 (Kling, 8초)
```

## 7. 허용/금지 페이로드

### 외부 API에 보낼 수 있는 것
- 텍스트 프롬프트 (장면 설명, 분위기, 카메라 방향)
- 참조 스틸 프레임 jpg (최대 3장, 원본 영상 아님)
- 생성 길이 (초)
- 스타일 파라미터

### 절대 보내지 않는 것
- 원본 영상 파일
- 원본 오디오
- 사용자 개인정보
- API 키 (서버 환경변수로만 관리)
