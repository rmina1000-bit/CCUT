# Free/Paid Analysis Policy (V1.0)

CCUT의 지속 가능한 운영과 사용자 혜택을 위한 무료/유료 서비스 정책입니다.

## 1. 무료 요금제 (Free Tier)
사용자의 로컬 자원을 최대한 활용하여 기본 기능을 제한 없이 제공하는 것을 원칙으로 합니다.

### 1.1. 제공 범위
- **기능 제한 없음**: 로컬 렌더링, 컷 편집, Export 기능 등 모든 편집 핵심 기능 무제한 제공.
- **분석 모드**: `video_use_speech_only` 및 `ccut_matrix_light` (경량 설정) 사용 가능.
- **로컬 분석**: 사용자 기기의 CPU/GPU를 이용한 분석은 회수 제한 없음.

### 1.2. 미지원 항목
- **아카이브 저장**: 분석된 매트릭스 데이터 및 의미 조각의 영구 서버 저장 불가.
- **상세 보고서**: 분석 결과에 대한 통계 리포트 생성 기능 미지원.
- **외부 AI 연동**: OpenAI, Anthropic 등 외부 유료 API를 이용한 고수준 분석 관리 기능 미지원.

## 2. 유료 요금제 (Paid - Standard)
- **가격**: 월 9,900원 (VAT 포함)
- **지향점**: 클라우드 기반 관리 서비스 및 외부 전문가용 AI 기능의 통합 관리.

### 2.1. 포함 기능
- **아카이브 가동**: 프로젝트별 분석 매트릭스를 서버에 동기화하여 여러 기기에서 협업 가능.
- **전문 분석 보고서**: 영상 내 감정 분포, 제품 노출 통계, 템포 분석 등이 포함된 PDF/Web 리포트 제공.
- **외부 AI 커넥터**: 유료 AI 모델(GPT-4, Claude 등)을 CCUT 내에서 통합 관리.
  - **API 키 관리**: 사용자가 자신의 API 키를 등록하여 사용.
  - **비용 관리**: CCUT이 외부 API 비용 추정, 호출 제한, 과금 알림 등 거버너(Governor) 역할 수행.

## 3. 비용 및 관리 정책 요약

| 항목 | 무료 (Free) | 유료 (Standard) |
|------|------|------|
| **기본 편집/렌더** | 무제한 | 무제한 |
| **로컬 분석** | 무제한 | 무제한 |
| **분석 정밀도** | Light 추천 | Full 추천 |
| **아카이브** | 미지원 (로컬만) | 지원 (서버 동기화) |
| **보고서 수신** | 미지원 | 지원 (상세 리포트) |
| **외부 AI 연동** | 미지원 | 지원 (커넥터 관리) |
| **외부 API 비용** | 해당 없음 | **사용자 별도 부담** |

## 4. 정책 배경
- CCUT은 "편집 도구"로서의 기본 기능에는 과금을 하지 않습니다.
- "데이터 관리(Archive)"와 "고급 지능(Web AI/Report)" 기능에 집중하여 유료 모델을 구축합니다.
- 외부 AI 호출 비용은 사용자가 사용한 만큼 직접 부담하게 하여 서비스 운영 리스크를 최소화합니다.
