# User Flow — Pre-Proposal Consultation

## Main Flow

1. User uploads videos.
2. CCUT analyzes videos locally.
3. CCUT creates semantic fragments and evidence.
4. CCUT does not immediately show A/B proposals.
5. CCUT first writes a narrative draft based on the analysis.
6. User reads the draft and responds naturally.
7. CCUT converts the response into StoryIntent.
8. CCUT then presents A/B proposals.
9. User previews A/B.
10. User commits one proposal or asks for adjustment.
11. ExportInput and Render proceed only after proposal selection.

## User Conversation Examples

User:
“아이 중심으로 해줘.”

CCUT:
“좋습니다. 사람과 표정, 움직임이 중심이 되도록 방향을 잡겠습니다.”

User:
“풍경은 조금만 쓰고 더 빠르게.”

CCUT:
“알겠습니다. 풍경은 분위기를 여는 정도로 줄이고, 전체 호흡은 더 빠르게 잡겠습니다.”

User:
“좋아, 이대로 제안해줘.”

CCUT:
“좋습니다. 이 기준으로 두 가지 편집안을 준비하겠습니다.”

## Principle

The user should feel that they are talking to an AI editor before editing starts.  
The user should not feel that the system has already decided the edit before asking.
