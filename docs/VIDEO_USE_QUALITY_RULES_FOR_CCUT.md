# Video-use Quality Rules for CCUT (V1.0)

Video-use 프로젝트에서 검증된 편집 품질 규칙을 CCUT 아키텍처에 맞게 재정의합니다.

## 1. 핵심 품질 규칙

### 1.1. 말 중간 컷 금지 (No Speech Mid-cut)
- **필요성**: 단어의 음절이 잘리면 편집의 완성도가 떨어지고 부자연스러움.
- **적용**: Semantic Fragment 생성 및 Proposal 정교화 단계.
- **무료 포함**: **YES** (기본 필수 품질)
- **주의점**: Word Timestamp 데이터와 컷 경계의 오차 범위를 상시 체크해야 함.

### 1.2. 컷 앞뒤 짧은 여유 유지 (Pad Start/End)
- **필요성**: 음성이 시작되기 직전과 끝난 직후에 미세한 여백(약 0.1s~0.2s)이 있어야 호흡이 자연스러움.
- **적용**: Render Engine의 Clip Metadata 생성 시점.
- **무료 포함**: **YES**
- **주의점**: 여유 공간이 너무 길면 늘어지므로 Context에 따라 가변 적용.

### 1.3. 컷마다 소리 튐 방지 (Zero-crossing / Cross-fade)
- **필요성**: 컷이 바뀔 때 파형이 불연속적이면 "뚝" 하는 노이즈(Pop) 발생.
- **적용**: Render Engine의 오디오 합성 파이프라인.
- **무료 포함**: **YES**
- **주의점**: CCUT Render Engine 내부에서 자동 페이드 인/아웃(30ms 내외) 처리 필수.

### 1.4. 자막 시간 재정렬 (Subtitle Retiming)
- **필요성**: 컷 편집 후 자막 싱크가 원본과 달라지므로 최종 타임라인 기준으로 재계산 필요.
- **적용**: ExportInput 생성 및 Render 단계.
- **무료 포함**: **YES**
- **주의점**: 컷이 생략된 구간의 자막은 삭제하고, 이어진 구간은 자연스럽게 병합.

### 1.5. 자막 최후순위 적용 (Post-FX Subtitles)
- **필요성**: 시각적 효과나 필터가 자막 위에 덮여 가독성이 떨어지는 현상 방지.
- **적용**: Render Engine의 레이어링 순서.
- **무료 포함**: **YES**
- **주의점**: 모든 레이어 오버레이 작업이 끝난 후 최상단에 렌더링.

### 1.6. 전사 결과 캐시 재사용 (Transcription Cache)
- **필요성**: 동일 소스에 대해 반복 분석 시 비용 및 시간 낭비 방지.
- **적용**: Virtual Fragment Factory의 Evidence Board 적재 로직.
- **무료 포함**: **YES**
- **주의점**: 소스 파일의 Hash(Fingerprint)가 바뀐 경우에만 재분석.

### 1.7. 작업 결과물 작업방 정리 (Isolated Working Dir)
- **필요성**: 분석/렌더 중 발생하는 임시 파일이 시스템을 어지럽히지 않도록 격리.
- **적용**: Resource Governor의 디렉토리 관리 정책.
- **무료 포함**: **YES**
- **주의점**: STEP 10-B의 Logical Room 단위로 폴더 구조화.

### 1.8. 편집 전 사용자 방향 확인 (User Intent Pre-check)
- **필요성**: AI가 제멋대로 편집하는 것이 아니라 사용자의 의도(길이, 톤)를 먼저 묻고 시작.
- **적용**: Quick Scan 후 User Intent 반영 단계.
- **무료 포함**: **YES**
- **주의점**: 사용자가 "확인" 버튼을 누르기 전에는 대규모 렌더링을 시작하지 않음.

### 1.9. 결과물 제공 전 컷 경계 검수 (Pre-render Boundary QA)
- **필요성**: 최종 렌더링 전 논리적 오류(중복 구간, 잘린 문장)를 자동 검수.
- **적용**: Proposal Engine 및 ExportInput 생성 단계.
- **무료 포함**: **YES**
- **주의점**: 정밀 분석은 유료일 수 있으나 기본 무결성 검사는 무료 포함.

## 2. 무료버전 기본 품질선 (Baseline Quality)
무료버전은 외부 고성능 AI(GPT-4 등) 없이도 **"사고 없는 결과물"**을 보장해야 합니다.
- **포함**: 규칙 1, 2, 3, 4, 5, 6 (필수 물리 품질 및 자막 싱크)
- **유료 확장**: 규칙 9의 딥러닝 기반 정밀 검수, 외부 AI를 통한 문맥적 자막 교정 등.
