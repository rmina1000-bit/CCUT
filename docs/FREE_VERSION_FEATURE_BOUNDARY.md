# Free Version Feature Boundary (V1.0)

CCUT 무료버전과 유료버전의 기능적 경계를 명확히 정의하여, 무료 사용자가 실질적인 가치를 경험할 수 있도록 합니다.

## 1. 무료 요금제 원칙
- **원칙**: 아카이브, 보고서, 외부 AI를 제외한 모든 **로컬 편집 기능**은 무제한/무료로 제공됩니다.
- 단순 체험판이 아닌, 개인 창작자가 로컬에서 충분히 편집을 마칠 수 있는 도구를 제공하는 것을 목표로 합니다.

## 2. 무료 포함 기능 (Free)
- 모든 로컬 분석 기능 (Matrix Light 등).
- 모든 조각 기반 편집 인터페이스 (Fragment Manager).
- 모든 물리적 품질 보정 규칙 (Video-use Rules).
- 무제한 로컬 렌더링 및 Export.

## 3. 무료 제외 기능 (Excluded - Paid Only)
- **장기 아카이브**: 분석된 데이터 및 프로젝트의 서버 저장 및 동기화.
- **분석 리포트**: 영상별 상세 감정/객체 통계 보고서 수신.
- **AI 기획자**: 외부 고성능 AI(LLM)를 통한 자연어 채팅 편집 및 재제안.
- **기억 패키지**: 이전 편집 스타일을 기억하여 다음 프로젝트에 선반영하는 기능.
- **Profile 저장**: Creator, Video, Quality 관련 메타데이터의 장기 서버 저장.
- **협업 기능**: 팀 단위 프로젝트 공유 및 동시 작업.
- **SNS 기록**: 업로드 이력 및 통계의 장기 관리.

## 4. 핵심 차별화 포인트
- **무료**: 로컬에서 "지금 이 영상"을 편집하는 기능에 집중.
- **유료**: 프로젝트를 "기억"하고, 여러 영상을 아우르는 "조언"을 제공하는 데 집중.
