# Report: Proposal-Level Seek Controller (STEP 10-K-C1-R4)

## 1. 개요
편집제안영상은 여러 조각(Fragment)이 시퀀스로 재생되는 구조이므로, 단일 비디오의 `currentTime`만으로는 전체 제안 영상의 시점 이동을 구현할 수 없다. 이를 해결하기 위해 전체 제안 영상 시간축(Global Time)을 기준으로 하는 전용 탐색 컨트롤러를 구현하였다.

---

## 2. 기존 방식의 한계 및 수정 방향
*   **한계:** Native Video Control의 재생바는 현재 로드된 개별 비디오 소스의 길이에 종속되므로, 조각이 바뀌면 진행바의 위치와 의미가 초기화되거나 튕기는 현상이 발생함.
*   **수정 방향:** 개별 비디오 조작과는 별개로, Proposal 전체 시퀀스의 누적 재생 시간을 추적하고 제어하는 전용 계층을 추가함.

---

## 3. 주요 구현 내용

### [시간 변환 로직 (resolveProposalTime)]
*   전체 시간(Global Time)을 입력받아, 해당 시간이 시퀀스 내의 **몇 번째 조각(Index)**의 **어느 지점(Offset)**인지를 계산하는 헬퍼 함수를 구현함.

### [제안 레벨 Seek 함수 (seekProposal)]
*   사용자가 전체 진행바를 조작하면 호출됨.
*   타겟 조각으로 소스(`src`)를 변경해야 하는 경우 `playFrag`를 호출하고, 동일 소스 내 이동인 경우 `currentTime`만 즉시 조정함.
*   소스가 변경되는 경우를 대비해 `pendingSeekRef`를 사용하여 비디오 메타데이터가 로드된 직후 정확한 위치로 점프하도록 함.

### [전용 진행바 UI]
*   Draft A(Primary), Draft B(Indigo) 각각의 영상 하단에 Proposal 전체 길이를 `max`로 하는 커스텀 `input[type="range"]`를 추가함.
*   드래그 중에는 `isDraggingProposalSeekRef`를 통해 `onTimeUpdate`의 자동 갱신을 차단하여 조작의 부드러움을 확보함.

### [onTimeUpdate 고도화]
*   현재 재생 중인 조각의 누적 시간(`seqElapsedSecRef`)과 비디오의 현재 로컬 시간(`currentTime`)을 합산하여 전체 진행 상태를 실시간으로 업데이트함.
