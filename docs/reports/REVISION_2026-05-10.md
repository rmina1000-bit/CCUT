## R-2026-05-10 — Proposal Preview Render 전환

**날짜:** 2026-05-10  
**판정:** Backend RUNTIME PASS / Frontend CODE PASS / Browser PASS / Product PASS

### 문제
A/B 제안 preview 재생 시 조각 누적 재생, A/B 에코, 중간 멈춤.

### 원인
브라우저 `<video>` currentTime seek로 원본 mp4를 편집 타임라인처럼 재생하는 구조적 오류.

### 해결
- `proposal_preview_engine.py` 신규: sequence clips → re-encode → concat → faststart mp4
- API 응답에 `preview_url` 주입
- Frontend: `src=preview_url, currentTime=0, play()` — seek 없음
