## 2. 관찰 현상
- 브라우저 Network 탭에서 일부 요청(이미지/비디오)이 `canceled` 상태로 표시됨.
- 현재 404(Not Found)나 500(Internal Server Error) 같은 실제 오류는 관찰되지 않음.
- 사용자 화면에서는 썸네일 표시 및 비디오 프리뷰가 정상적으로 작동함.

## 3. canceled 가능 원인
기술적으로 분석했을 때 다음과 같은 상황에서 브라우저가 의도적으로 요청을 중단(Cancel)합니다:

- **Video src 교체**: 사용자가 다른 조각을 선택하거나 재생 구간을 옮길 때 `<video>` 태그의 `src`가 바뀌면, 브라우저는 이전 `src`에 대해 진행 중이던 Byte Range Request를 즉시 중단합니다.
- **Proposal A/B 전환**: 제안 A와 B 사이를 빠르게 전환할 때, 이전 제안의 조각들을 렌더링하기 위해 시작된 썸네일(Thumbnail) 요청들이 새로운 제안 렌더링에 의해 '더 이상 필요 없음'으로 판단되어 중단될 수 있습니다.
- **React Component Unmount**: 화면 전환이나 모달 닫기 등으로 인해 요청을 보낸 컴포넌트가 사라질 때 `AbortController` 등에 의해 요청이 취소됩니다.
- **Hover/Seek**: 마우스 호버 등으로 여러 조각의 프리뷰를 시도하다가 마우스를 빠르게 치울 경우, 불필요한 네트워크 대역폭 낭비를 막기 위해 브라우저가 요청을 취소합니다.
