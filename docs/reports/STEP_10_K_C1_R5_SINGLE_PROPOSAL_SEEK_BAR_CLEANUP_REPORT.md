# Report: Single Proposal Seek Bar Cleanup (STEP 10-K-C1-R5)

## 1. 개요
편집제안영상 플레이어의 UI를 정돈하여 사용자의 혼동을 방지하고, 시퀀스 재생 구조에 최적화된 단일 탐색바 시스템을 완성하였다.

---

## 2. 주요 수정 내용

### [Native Video Controls 제거]
*   `<video>` 태그에서 `controls` 속성을 제거하여 브라우저 기본 컨트롤바(흰색 진행바 포함)를 숨김.
*   이로써 개별 비디오 소스 단위의 진행바와 Proposal 전체 단위의 진행바가 공존하던 문제를 해결함.

### [Proposal-Level Seek Bar 통합]
*   기존에 구현된 Proposal 전체 시간축 기준의 탐색바(파란색/남색)만 남겨 단일 인터페이스로 정리함.
*   재생/일시정지는 기존 카드 오버레이 버튼 및 클릭 이벤트를 통해 계속 제어 가능함.

### [진행바 Thumb(동그란 버튼) 제거]
*   `ccut_frontend/src/index.css`에 `.proposal-seekbar` 유틸리티 클래스를 추가함.
*   CSS의 `::-webkit-slider-thumb` 및 `::-moz-range-thumb` 속성을 사용하여 진행바의 동그란 Thumb를 제거함.
*   사용자에게는 오직 진행 상태를 나타내는 가느다란 트랙(Track)만 노출되며, 트랙 클릭/드래그를 통한 시점 이동 기능은 그대로 유지함.
