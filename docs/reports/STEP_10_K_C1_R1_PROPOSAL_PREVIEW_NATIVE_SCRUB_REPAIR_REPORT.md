# Report: Proposal Preview Native Scrub Repair (STEP 10-K-C1-R1)

## 1. 개요
편집제안영상(Draft A/B)의 진행바가 커스텀 구현으로 인해 조작감이 불안정하고 재생 위치가 튀는 현상을 해결하기 위해, 브라우저 표준에 가까운 안정적인 방식으로 재정리하였다.

---

## 2. 기존 문제점
*   **조작 불안정:** `div`와 `MouseEvent` 기반의 커스텀 스크럽 로직이 드래그 시 매끄럽지 못함.
*   **이벤트 충돌:** 진행바 조작 시 부모 요소의 `onClick` (play/pause 토글)이 함께 발생하여 의도치 않게 영상이 멈추거나 재생됨.
*   **시각적 피드백 부재:** 드래그 중인 위치가 시각적으로 명확하게 표시되지 않음.

---

## 3. 적용 방식 및 수정 내용

### [적용 방식] Input Range 기반 스크럽
Native `<video controls>`는 시퀀스 재생(여러 조각을 이어 붙여 재생) 특성상 전체 진행도를 표시하기 어려워, **`input type="range"`**를 기반으로 한 최소한의 표준 컨트롤을 구현하였다.

### [수정 파일]
*   `ccut_frontend/src/components/CenterPanel.tsx`

### [주요 코드 변경]
*   **표준 컨트롤 사용:** `input[type="range"]`를 도입하여 드래그/클릭 시 브라우저 기본 슬라이더 동작을 활용.
*   **이벤트 격리:** 
    *   `onClick`, `onMouseDown`, `onPointerDown`에 `e.stopPropagation()`을 적용하여 부모 카드의 play/pause 토글 간섭을 완벽히 차단.
*   **스타일링:** 
    *   `appearance-none`과 `linear-gradient`를 사용하여 배경색과 진행도를 프리미엄하게 표시.
    *   호버 시 높이가 확장(`h-1` -> `h-1.5`)되어 조작 편의성 증대.
