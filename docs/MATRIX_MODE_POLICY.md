# Matrix Mode Policy (V1.0)

분석 깊이와 하드웨어 리소스 최적화를 위한 Cognitive Signal Matrix 분석 모드 정책입니다.

## 1. 모드별 상세 사양 및 10-E1 결과값

### 1.1. video_use_speech_only
- **정의**: 오직 음성 및 기본적인 오디오 에너지 신호만 분석합니다.
- **용도**: 말 중심의 빠른 초안 생성, 텍스트 기반 편집.
- **측정 결과 (60s 기준)**:
  - **평균 처리 시간**: 0.8s
  - **경계 정밀도**: 0.62
- **장점**: 압도적인 속도, 저사양 기기에서 즉각적인 결과 제공.

### 1.2. ccut_matrix_light
- **정의**: Speech, Scene, Motion, Audio, Rhythm 신호를 결합한 핵심 분석 모드입니다.
- **용도**: 일반적인 브이로그, 인터뷰, 제품 리뷰 영상의 기본 추천 모드.
- **측정 결과 (60s 기준)**:
  - **평균 처리 시간**: 16.01s
  - **경계 정밀도**: 0.88
- **최적 설정**: **2s Row Size + 8 Worker Slots** (10-E1 검증 완료)
- **장점**: 높은 정밀도와 합리적인 대기 시간의 균형.

### 1.3. ccut_matrix_full
- **정의**: 지원하는 모든 인지 신호(Person, Event, Entropy, Focus Object 등)를 동원하는 정밀 분석 모드입니다.
- **용도**: 전문적인 아카이브 구축, 고도화된 하이라이트 추출.
- **측정 결과 (60s 기준)**:
  - **평균 처리 시간**: 96.06s
  - **경계 정밀도**: 0.97
- **단점**: 연산 부하가 매우 커서 실시간 편집보다는 비동기 백그라운드 처리 권장.

## 2. 모드 자동 선택 로직 (향후 구현 예정)
- **HW Profile**: `NORMAL_LAPTOP` 환경에서는 `Light` 이하 강제 적용.
- **Source Duration**: 10분 이상의 장편 영상은 `Speech-only`로 우선 추천.
- **User Preference**: 정밀도가 생명인 작업은 `Full` 모드 선택 가능(유료).

## 3. 요약 및 권장 사항
| 모드 | 속도 | 정밀도 | 권장 하드웨어 | 용도 |
|------|------|------|------|------|
| **Speech-only** | 극히 빠름 | 낮음 | 전 기종 | 빠른 텍스트 컷 편집 |
| **Matrix Light** | 보통 | 높음 | 중급 사양 이상 | **표준 편집 (기본값)** |
| **Matrix Full** | 느림 | 최고 | 고사양 워크스테이션 | 정밀 분석 및 자동 하이라이트 |
