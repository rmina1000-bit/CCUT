# Free Form UI Minimum Specification (V1.0)

CCUT 무료 사용자가 편집 전문 지식 없이도 직관적으로 편집 의도를 입력하고 결과를 확인할 수 있는 UI의 최소 사양입니다.

## 1. 목적
- 초보 사용자가 "타임라인 편집" 대신 "선택과 조각 관리"를 통해 영상 편집을 완성할 수 있는 경험 제공.
- 시각적 피로도를 낮추고 전문성을 강조하는 흑백/무채색 기반의 정갈한 인터페이스 확립.

## 2. 화면 3단 구조 (The 3-Panel Layout)
1. **좌측 패널 (Sidebar)**: 프로젝트 관리 및 시스템 메뉴.
2. **중앙 패널 (Form Area)**: 핵심 가치인 "무료 편집 폼"이 위치하는 메인 작업 영역.
3. **우측 패널 (Working Area)**: 분석 결과(파노라마), 조각 보드, 미리보기 및 출력.

## 3. 핵심 기능 (Must-Have)
- **폼 입력**: 8가지 항목(목적, 길이, 스타일 등)의 선택 인터페이스.
- **조각 작업**: 추천된 조각들의 살리기/빼기/순서 변경 등의 상태 조작.
- **미리보기**: 편집 결과의 즉시 확인.
- **로컬 출력**: 최종 mp4 렌더링 및 저장.

## 4. 사용자 기본 흐름
1. **New Project**: 좌측 상단 버튼을 통해 영상 업로드.
2. **Form Fill**: 중앙에서 원하는 편집 스타일과 목적 선택.
3. **Generate**: "편집안 생성" 버튼 클릭.
4. **Fragment Edit**: 우측 조각 보드에서 제안된 조각들 검토 및 개입.
5. **Render & Export**: 하단 우측 버튼으로 최종 영상 출력.

## 5. 완료 기준
- 3단 레이아웃이 명확하게 구분될 것.
- 흑백/무채색 디자인 원칙이 모든 컴포넌트에 적용될 것.
- 무료 편집 폼의 8개 항목이 조작 가능한 UI 형태로 설계될 것.
- 조각 보드의 7가지 액션이 아이콘/텍스트로 명시될 것.
