# Free Form UI Style Guide (V1.0)

CCUT의 브랜드 정체성과 무료 버전의 전문성을 유지하기 위한 시각적 스타일 가이드입니다.

## 1. 컬러 시스템 (Monochrome Only)
다색 사용을 엄격히 금지하며, 명도와 테두리를 통해 계층을 구분합니다.

| 요소 | 컬러/스타일 | 설명 |
|------|------------|------|
| **배경** | `#0A0A0A` (Deep Black) | 다크 모드의 깊이감 강조 |
| **패널/카드** | `#1A1A1A` (Dark Gray) | 배경과 미세하게 구분되는 레이어 |
| **선/경계** | `#333333` (Mid Gray) | 요소 간의 구분선 |
| **기본 텍스트** | `#E0E0E0` (Off White) | 높은 가독성 확보 |
| **보조 텍스트** | `#888888` (Gray) | 덜 중요한 정보 |
| **선택 상태** | `White Border` / `#2A2A2A` | 배경은 약간 밝게, 테두리는 흰색으로 강조 |

## 2. 버튼 및 인터페이스 (Buttons & Interaction)
- **다색 금지**: 파랑, 보라, 빨강 등의 유채색 버튼을 사용하지 않습니다.
- **강조 기법**:
  - **Primary CTA**: 배경은 화이트에 가까운 연회색, 텍스트는 블랙 (반전 스타일).
  - **Secondary CTA**: 어두운 배경에 흰색/연회색 테두리.
- **위험/경고**: 빨간색 대신 `Warning` 아이콘과 함께 `Mid Gray` 텍스트 사용.
- **성공/완료**: 초록색 대신 `Check` 아이콘 사용.

## 3. 타이포그래피 및 계층
- **Headline**: 명확하고 굵은 폰트, 흰색.
- **Label**: 중간 굵기, 밝은 회색.
- **Description**: 얇은 굵기, 중간 회색.

## 4. 아이콘 사용 원칙
- 흑백 테마에 어울리는 **Line-based** 또는 **Solid Mono** 아이콘 세트 사용.
- 색상 변화 없이 크기와 명도 차이로만 의미를 전달.

## 5. 디자인 목표
- **차분함 (Calmness)**: 시각적 자극을 최소화하여 편집 자체에 집중 유도.
- **전문성 (Professionalism)**: 고가의 전문가용 장비 인터페이스와 같은 진중함 유지.
- **시각 피로 감소**: 다크 테마와 무채색 조합으로 장시간 작업에도 편안함 제공.
